# 🔗 SHORTLINKS

## 📝 O que é
Um encurtador e redirecionador de URLs Web desenvolvido para simplificar o compartilhamento de links muito grandes.

## ⚙️ Como funciona
*   **Banco de Dados**: Utiliza uma API de banco de dados relacional para fazer a associação e o armazenamento seguro dos links.
*   **Redirecionamento**: Utiliza o **Cloudflare Pages** e **Functions** para processar e efetuar o redirecionamento de forma rápida e eficiente.

## 🛠️ Tecnologias usadas
Abaixo estão as principais tecnologias e ferramentas aplicadas no desenvolvimento do projeto:

| Categoria | Tecnologias |
| :--- | :--- |
| **Front-end** | HTML5, CSS3, JavaScript (Vanilla) |
| **Back-end / Serverless** | Cloudflare Pages & Functions |
| **Banco de Dados** | Supabase |
